تسجيل الحساب والدخول:
- المستخدم يكتب اسم المستخدم وكلمة المرور فقط.
- لا توجد خانة بريد إلكتروني أو اسم إضافي.
- تقنيًا يستخدم النظام عنوانًا داخليًا مشتقًا من اسم المستخدم للتوافق مع Supabase Auth؛ هذا لا يظهر للمستخدم.
- لكي يتم إنشاء الحساب والدخول مباشرة دون رسالة تأكيد، يجب تعطيل Confirm email من Supabase Dashboard > Authentication > Providers > Email.
- هذا التعديل لا يغير بيانات الحسابات القديمة. استخدم اسم المستخدم وكلمة المرور اللذين أنشأت بهما الحساب سابقًا.

النشر:
ارفع محتويات المجلد كما هي إلى جذر الموقع، بحيث يكون index.html في الجذر، وليس داخل مجلد فرعي.
