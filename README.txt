SHADOW FILES — النسخة الكاملة

الملفات:
- index.html: الصفحة الرئيسية، القضية والأرشيف واختبار أكاديمية المحققين.
- cipher.html: تطبيق الشفرات السرية.
- sw.js: عامل الخدمة والتخزين المؤقت.
- manifest.webmanifest: بيانات تثبيت التطبيق.
- icon.svg: أيقونة التطبيق.

للتشغيل:
افتح index.html في متصفح حديث.
للنشر على GitHub Pages: ارفع محتويات هذا المجلد إلى جذر المستودع، وليس ملف ZIP نفسه.
